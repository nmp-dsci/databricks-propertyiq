How it got deployed

Same loop as the medallion pipeline — nothing new. The key mental model: make deploy uploads the local working tree, not a git branch. Git/CI validate; only your machine deploys.

The loop that shipped each phase

  1. make test — 48 unit tests on local Spark prove features, gate and forecasters in ~21s
  2. make validate — type-checks databricks.yml + all resource YAMLs, no upload
  3. make deploy — uploads the tree to /Workspace/Users/<you>/.bundle/databricks-propertyiq/dev/files/ and creates/updates jobs + endpoint
  4. databricks bundle run ml_train -t dev — trains, registers, gates; logs stream to the terminal
  5. databricks bundle run ml_score -t dev — scores, computes drift, auto-retrains if shifted
  6. Iterate: three real issues were found by running (spark_udf break, PSI treadmill ×2), fixed locally, redeployed

What landed where

  • jobs[dev …] propertyiq-ml-train / -ml-score / -ml-forecast — dev-mode name prefix
  • modelworkspace.propertyiq_ml.rent_estimator — v1 @champion, v3 @challenger
  • endpointdev_nathanphillips369_propertyiq-rent-estimator — dev prefix resolved into the job via ${resources.…name}
  • tables8 tables in propertyiq_ml — features, predictions, drift, accuracy, 4 forecast tables
  • experiment/Users/…/propertyiq-rent-estimator — one MLflow run per training
  • gateno-mistakes pipeline: review → test → docs → lint → push → PR #3 → CI green

2 · From SQL, via ai_query()

SQL Editor on the warehouse, or from the repo: make sql FILE=src/sql/03_ml_ai_query.sql (swap in the dev-prefixed endpoint name).

SELECT ai_query(
  'dev_nathanphillips369_propertyiq-rent-estimator',
  named_struct('postcode','2327','property_type','house',
    'bedroom_band','3','rent_lag_1',520.0, ...),
  returnType => 'DOUBLE');

3 · The whole loop, from the terminal

databricks bundle run ml_train -t dev    # retrain + gate
databricks bundle run ml_score -t dev    # score + drift
databricks bundle run ml_forecast -t dev # comparison

Watch the train run's log print the gate verdict — "CHAMPION STANDS" or "PROMOTED" — then refresh the registry page (stop 03) to see aliases move.

4 · Ask the data

In the SQL editor (or via the Genie bar on any propertyiq_ml table):

SELECT * FROM propertyiq_ml.prediction_accuracy;
SELECT * FROM propertyiq_ml.drift_metrics
ORDER BY psi DESC;
SELECT method, round(avg(mae),4) avg_mae
FROM propertyiq_ml.forecast_comparison
GROUP BY method ORDER BY avg_mae;
